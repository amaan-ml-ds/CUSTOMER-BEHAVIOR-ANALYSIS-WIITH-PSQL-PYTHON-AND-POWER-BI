# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across different product categories. It combines exploratory data analysis in Python, business-focused SQL queries, and a Power BI dashboard to investigate spending patterns, product preferences, customer segments, shipping choices, discounts, and subscription behavior.

The goal is to turn purchase data into actionable insights that can support marketing, customer retention, product positioning, and subscription strategies.

## Objectives

- Explore and clean customer shopping data using Python and Pandas.
- Handle missing product review ratings.
- Standardize column names and engineer useful features.
- Load the prepared dataset into a relational database for SQL analysis.
- Answer business questions using aggregation, filtering, subqueries, CTEs, and window functions.
- Present results in a Power BI dashboard.
- Derive recommendations for customer loyalty, subscriptions, discount policy, and targeted marketing.

## Python Data Preparation

The notebook follows these steps:

1. **Load the dataset** using `pandas.read_csv()` from `customer_shopping_behavior.csv`.
2. **Inspect the data** with `head()`, `info()`, `describe(include='all')`, and `isnull().sum()`.
3. **Handle missing ratings** by filling missing `Review Rating` values with the median rating within the corresponding `Category`.
4. **Standardize column names** by converting them to lowercase, replacing spaces with underscores, and renaming `purchase_amount_(usd)` to `purchase_amount`.
5. **Create age groups** with `pd.qcut()` to split `age` into four quantile-based groups labelled `Young Adult`, `Adult`, `Middle-aged`, and `Senior`.
6. **Convert purchase frequency to days** using a mapping:
   - Weekly → 7
   - Fortnightly / Bi-Weekly → 14
   - Monthly → 30
   - Quarterly / Every 3 Months → 90
   - Annually → 365
7. **Check discount and promo fields** by comparing `discount_applied` with `promo_code_used`; the notebook drops `promo_code_used` after checking whether the two fields match.

## SQL Business Questions

The SQL script contains ten queries:

| # | Business question | SQL techniques |
|---:|---|---|
| 1 | What is the total revenue generated by male vs. female customers? | `SUM()`, `GROUP BY` |
| 2 | Which customers used a discount but still spent at least the average purchase amount? | Filtering, scalar subquery, `AVG()` |
| 3 | Which five products have the highest average review rating? | `AVG()`, `ROUND()`, sorting, `LIMIT` |
| 4 | How do average purchase amounts compare between Standard and Express shipping? | `AVG()`, `WHERE`, `GROUP BY` |
| 5 | Do subscribers spend more? Compare customer counts, average spend, and total revenue by subscription status. | `COUNT()`, `AVG()`, `SUM()`, `GROUP BY` |
| 6 | Which five products have the highest percentage of purchases with discounts applied? | `CASE`, conditional aggregation, percentage calculation |
| 7 | How many customers fall into New, Returning, and Loyal segments based on previous purchases? | CTE, `CASE`, `GROUP BY` |
| 8 | What are the three most purchased products within each category? | CTE, `ROW_NUMBER()` window function, partitioning |
| 9 | Among customers with more than five previous purchases, how many are subscribers vs. non-subscribers? | Filtering, `COUNT()`, `GROUP BY` |
| 10 | What is the revenue contribution of each age group? | `SUM()`, `GROUP BY`, sorting |

### Customer Segmentation Logic

The SQL script classifies customers according to `previous_purchases`:

- **New:** exactly 1 previous purchase.
- **Returning:** 2–10 previous purchases.
- **Loyal:** all other values, including values above 10 and any values not covered by the first two conditions.

This is the classification implemented in the SQL query.

## Setup and Execution

### 1. Install Python dependencies

```bash
pip install pandas sqlalchemy psycopg2-binary jupyter
```

### 2. Prepare the input data

Place `customer_shopping_behavior.csv` in the same working directory as the notebook. The CSV is referenced by the notebook but was not among the supplied project files.

### 3. Prepare PostgreSQL

Create a PostgreSQL database named `customer_behavior`, or update the notebook to use your own database name and connection details. Ensure PostgreSQL is running and that the account has permission to create or replace the `customer` table.

### 4. Run the notebook

```bash
jupyter notebook Customer_Shopping_Behavior_Analysis.ipynb
```

Run the cells in order. Review and update the database connection cell before executing it. The notebook uses `if_exists='replace'`, which replaces an existing `customer` table with the DataFrame contents.

### 5. Run the SQL analysis

Open `customer_behavior_sql_queries.sql` in a PostgreSQL client such as pgAdmin or `psql` and execute the queries after the `customer` table has been loaded.

The SQL uses PostgreSQL syntax, including `review_rating::numeric`, CTEs, and window functions.
